Date: 2026-05-06

18. NEW: lib/models/user_model.dart
    - Data model for app user: uid, email, childName, birthday, disorderType1, disorderType2, createdAt
    - toMap() for Firestore writes, factory fromMap() for reads
    - copyWith() for immutable updates

19. NEW: lib/controllers/auth_controller.dart
    - ChangeNotifier-based controller for Firebase Auth + Firestore
    - signUp(email, password) — creates account via FirebaseAuth
    - logIn(email, password) — signs in, fetches user profile
    - logOut() — signs out, clears profile
    - saveUserProfile(UserModel) — writes to Firestore users/{uid}
    - fetchUserProfile() — reads profile from Firestore
    - Arabic-localized error messages for all FirebaseAuthException codes
    - Exposes isLoading, errorMessage, user, userProfile, authStateChanges
