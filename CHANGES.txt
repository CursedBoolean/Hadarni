26. NEW: tools/whisper_server.py
    - FastAPI server that loads the fine-tuned Whisper model from
      whisper-finetuned-arabic/ at project root
    - GET  /health  — liveness check, returns device (cpu/cuda)
    - POST /transcribe — accepts multipart (audio file + target string)
      • Uses librosa to resample to 16 kHz mono (Whisper's native format)
      • Runs WhisperForConditionalGeneration.generate() with language=ar
      • Normalises Arabic before comparison: strips diacritics, unifies
        alef variants (أإآ→ا), ta-marbuta (ة→ه), ya (ى→ي)
      • Returns {transcript, is_correct, target, target_normalised,
                 transcript_normalised}
    - CORS middleware enabled (allow_origins=*)
    - Fixed server warnings:
      • Explicit attention_mask (ones tensor) to silence pad==eos warning
      • suppress_tokens=[] and begin_suppress_tokens=[] passed to
        model.generate() to prevent duplicate logits processor creation

27. NEW: tools/requirements.txt
    - Python dependencies: fastapi, uvicorn[standard], transformers,
      torch, librosa, python-multipart, numpy, soundfile
    - Start server with:
        python -m uvicorn tools.whisper_server:app --host 0.0.0.0 --port 8000 --reload

28. NEW: lib/services/whisper_service.dart
    - WhisperResult model: {transcript, isCorrect, target}
    - WhisperService.transcribe(audioPath, target) — multipart POST

    - WhisperServerException typed error class
    - baseUrl = http://10.0.2.2:8000 (Android emulator loopback)
